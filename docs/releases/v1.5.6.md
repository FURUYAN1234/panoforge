# PanoForge v1.5.6

## Changes / 更新内容

- API settings verify the key through the provider’s model list. Keys with restricted access to the list are marked unverified. Re-entering a rejected key for the same provider keeps the source image, settings, and current view. / API設定時にモデル一覧でキーを確認します。一覧だけ権限がない場合はキー未確認と表示します。拒否されたキーを同じ提供元で入れ直す場合は、原画・設定・ビューが残ります。
- HD captures save a 1920×1080 PNG through a browser Blob URL and restore the current view after success or failure. The viewer reports encoding failures. PNG exports preserve PNG bytes, and 360° JPEGs continue to include GPano metadata. / HDキャプチャはブラウザーのBlob URLから1920×1080のPNGとして保存し、失敗時も元のビューへ戻ります。ビューワーは保存エラーを表示します。PNGのデータはそのまま保存し、360°JPEGには従来どおりGPano情報を付けます。

## Windows readback / Windowsでの動作確認

- On Windows, the app opened an existing 6144×3072 panorama and downloaded a 1920×1080 PNG from the viewer’s Capture button. The saved PNG opened and decoded successfully. / Windowsで、手元の6144×3072のパノラマを開き、「キャプチャ保存」で1920×1080のPNGを書き出して読み戻しました。
