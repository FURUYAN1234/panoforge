## Release Guard / リリースガード

- **Preflight-first deployment / 事前検査を先行するデプロイ**: The standard deploy command now runs release preflight before it can publish Pages. / 標準デプロイコマンドは、Pagesを公開する前に必ずリリース事前検査を実行します。
- **Version-derived notes / バージョン連動ノート**: Preflight derives the required bilingual release-notes filename from the current package version, so a release cannot accidentally use stale notes. / 事前検査は現在のpackage versionから必要な英日併記リリースノート名を導出するため、古いノートを誤って使うリリースを防ぎます。

## Verification / 検証

- **Fail-closed coverage / フェイルクローズ検証**: Regression tests verify the standard deploy path includes preflight, version-derived notes pass, and missing notes are rejected before publication. / 回帰テストで、標準デプロイ経路の事前検査、バージョン連動ノートの成功、ノート欠落時の公開前拒否を確認しました。
