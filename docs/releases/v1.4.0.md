## Provider Isolation / プロバイダ分離

- **Independent provider paths / 独立したプロバイダ経路**: Gemini and OpenAI are explicitly isolated execution paths. Each provider retries only models from its own provider family; cross-provider fallback is forbidden. / GeminiとOpenAIは明示的に分離された実行経路です。各プロバイダは同じプロバイダ系列のモデルだけを再試行し、プロバイダをまたぐフォールバックは禁止です。
- **State reset on switch / 切替時の状態消去**: Changing provider clears the source image, panorama, viewer, and retry state. A new image must be created or uploaded after the switch. / プロバイダ変更時に元画像・パノラマ・ビューワー・再試行状態を消去します。切替後は新しい画像を生成またはアップロードする必要があります。
- **Clear model-chain display / モデルチェーン表示の明確化**: Model Chain renders each fallback as provider-local rather than combining providers under one step. / Model Chainは複数プロバイダを同じステップに混在させず、各フォールバックをプロバイダ内のものとして表示します。
