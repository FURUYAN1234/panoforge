# 360 AI Panorama Generator v1.4.5

## Gemini image generation / Gemini画像生成

- Use Nano Banana 2.1 (`gemini-nano-banana-2.1`) through the Interactions API for image generation, panorama expansion and spatial repair. / 画像生成・パノラマ拡張・空間修正をNano Banana 2.1 (`gemini-nano-banana-2.1`) のInteractions APIへ更新しました。
- Share the image-model configuration between execution and the STEP1/STEP2 Model Chain display, removing the obsolete Gemini image fallback. / 実処理とSTEP1・STEP2のModel Chain表示で画像モデル設定を共通化し、旧Gemini画像モデルへのフォールバックを外しました。
- Omit the SDK revision header rejected by browser CORS checks. / ブラウザーのCORS検査で拒否されるSDKのリビジョンヘッダーを除き、画像生成の通信失敗を修正しました。
- Mask API keys before paste and typing, and when settings are opened or closed. Explicit reveal remains available. / APIキーの貼り付け・入力前と設定画面の開閉時に伏せ字へ戻します。表示ボタンでの確認は引き続き使えます。
