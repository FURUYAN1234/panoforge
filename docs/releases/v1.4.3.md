# 360 AI Panorama Generator v1.4.3

## What's New / 更新内容

- **OpenAI model selector / OpenAIモデル選択:** All 11 text/vision models are selectable, with Astra first and GPT-6.1 Sol selected by default in development and production. Descriptions and input/output pricing accompany the selection. Scene/style suggestions, input-image analysis and spatial checks start at the selected model and fall back only downward. / OpenAIのテキスト・画像解析モデル11種類を選択できます。Astraを先頭、開発版・公開版ともGPT-6.1 Solを初期選択とし、説明と入力・出力料金を表示します。シーン・スタイル提案、入力画像の詳細解析、空間構成の確認は選択したモデルから開始し、下位にだけ切り替えます。
- **Selection, attempts and adoption / 選択・試行・採用:** Separate text and vision statuses show actual attempted and adopted models. A previous successful fallback never overrides the next request's selected starting model. Model changes are blocked during active routes. / テキストと画像解析の各欄で、選択モデル、実際に試行したモデル、採用モデルを表示します。以前成功した下位モデルが次の処理の選択を上書きすることはありません。処理中のモデル変更を止めます。
- **Request and response handling / リクエスト・応答処理:** GPT-6/GPT-5.6 use reasoning-compatible completion parameters and a 120-second timeout; legacy payloads are retained. Truncated or refused output is rejected; authentication, access and quota failures stop the chain. / GPT-6・GPT-5.6の推論対応パラメーターと120秒のタイムアウトに対応し、旧モデルの互換パラメーターを維持します。途中終了・拒否された応答は完成扱いせず、認証・アクセス・利用枠エラーによる連続試行を止めます。
- **Provider and image boundaries / プロバイダー・画像生成の境界:** Existing Gemini and image-generation routes are retained. / Geminiと画像生成の既存経路を維持します。

## Validation / 検証

Local tests cover all 11 models' text/vision payloads, default and downward routes, status, selection locking, Gemini isolation and response rejection. Live API validation and official publication are confirmed separately at release time. / 11モデルのテキスト・画像解析リクエスト、既定・下位経路、試行・採用表示、処理中の選択制限、Gemini分離、応答の拒否をローカルテストで確認します。実API検証と公式公開の完了はリリース時に別途確認します。
