# PanoForge v1.4.9

## Changes / 更新内容

- [OpenAI Image] Use GPT Image 2.6 Sunburst / xhigh first for base images, 360° expansion and edits, with GPT Image 2.0 / high for eligible provider errors. / OpenAIの元画像生成・360°拡張・部分編集はGPT Image 2.6 Sunburst / xhighを優先し、対象のエラーではGPT Image 2.0 / highに切り替えます。
- [OpenAI 360° Expansion] Request 2048×1024 and validate 2:1 dimensions. Compare the original reference, full panorama, centered seam and a 90° perspective view facing the seam before displaying the result. / 2048×1024を指定し、実寸が2:1か確認します。元画像、全周画像、中央へ移したつなぎ目、つなぎ目を正面から見た90°の視野を検査してから表示します。
- [Seam correction] Apply one masked edit for defects confined to the wrap seam. The app keeps the surrounding image and checks the repaired panorama again. / つなぎ目だけに不具合があれば、該当部分を1回だけ画像編集します。周囲の画像を保持し、補正結果を再検査します。
- [Reference preservation] Project the source onto the sphere and outpaint the missing directions using the image and mask. Preserve the observed region and offer rejected images separately for inspection. / 元画像を球面へ投影し、画像とマスクを使って見えていない方向を補います。元画像の領域を保持し、不合格画像も完成品と分けて確認できます。
