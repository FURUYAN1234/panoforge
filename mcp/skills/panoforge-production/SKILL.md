# PanoForgeで360度背景を作る

1. 用途、正面に残すランドマーク、空間の前後左右、光の向き、勝手に追加してはいけない物を整理する。参照画像がある場合は、その条件と、見えていない背面をどう補うかを分ける。
2. 既存の元画像が条件を満たす場合は、元画像生成を繰り返さず360度拡張に使う。元画像と完成パノラマを分けて管理し、指定のプロバイダーを勝手に切り替えない。
3. 平面の2:1画像だけで採否を決めない。球面ビューアで正面・背面・左右と上下を調べ、左右端が出会う方角を横切って道、手すり、壁、地平線が物理的につながるかを追う。色がなじんでいても、構造の段差・分岐や主要物体の重複は不具合とする。
4. 不具合がつなぎ目だけなら部分補正で済むかを確認し、広範囲なら空間の指定と元画像に戻る。360度ビューアへの納品では、保存したファイルの2:1とGPanoメタデータを確認し、必要ならそのファイルを開き直して見え方を確かめる。
5. MCP利用時は対象アプリの接続と、実際の生成・状態取得・出力形式を確認する。MCPが使えなければ通常画面か既存画像の検査を進め、どこまで実施したかを伝える。
